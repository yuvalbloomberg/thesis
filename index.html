טעינת מסמך

כל מאמר בשורה נפרדת עם הקישור בתוך השם או לצדו, והציטוטים ממנו בשורות שמתחתיו. כתוב בראש המסמך "נקודת ציון: צוק איתן" והכלי יזהה אותה. אפשר להדביק כאן ישירות מוורד או מגוגל דוקס (הקישורים נשמרים), או לבחור קובץ וורד, HTML או טקסט.

יעד ותיוג

התיוג האוטומטי מסמן את הציטוטים כ"ממתינים לאישור", ומילוי השדות מופיע כהצעות — שום דבר לא נחשב מאושר עד שתאשר.

ייבוא מקובץ JSON

רשימת פריטים עם השדות: speaker, quote, event_date, stance (confirms / refutes), source_type (tweet / article / interview / protocol / official_document / speech / other), primary_url, cited_source_url, publish_date. פריטים עם אותו primary_url מתאחדים למקור אחד, ומקור קיים עם אותו קישור מקבל את הציטוטים החדשים.

יעד

המרכיב שתבחר יתויג לכל הציטוטים בייבוא הזה. העמדה נשמרת כ"כיוון" בציטוט, בלי תיוג השערות אוטומטי.

שאילתות על הציטוטים
סריקת פרוטוקולי הכנסת

1. טווח וזירות

ברירת המחדל: שלושה חודשים לפני האירוע עד ארבעה חודשים אחריו. רוב ישיבות ועדת החוץ והביטחון חסויות, ולכן יופיעו בעיקר ישיבות פתוחות והמליאה.

2. מה לחפש

דוברים
מילות מפתח (לפחות אחת צריכה להופיע בקטע הדיבור)
הגדרות חיבור

הכלי ניגש למאגר הרשמי של הכנסת דרך Worker קטן, כי מהדפדפן אי אפשר להוריד ישירות את קובצי הפרוטוקולים.

סקירת עיתונות שיטתית

1. טווח וזירה

הסריקה מוגבלת לרשימת כלי התקשורת שמוגדרת למטה. פירוק החלון לחודשים מצמצם את ההחמצה בטווחים ארוכים, במחיר של יותר שאילתות.

2. רשת מילות המפתח

מושגים
כלי תקשורת (דומיינים, מופרדים בפסיק)
שחקנים ופרשנים (שורה לשורה או מופרדים בפסיק)

3. הרצה

הגדרות מנוע החיפוש

המפתח נשמר בדפדפן שלך בלבד. אם הדפדפן חוסם את הפנייה הישירה, הכלי ינסה דרך ה-Worker אם הגדרת כתובת. מכסת החינם של Serper היא כ-2,500 שאילתות.

הצלבה לפי שחקן

ציטוט משויך לשחקן לפי שדה הדובר. מקורות רשמיים: פרוטוקול, דו"ח ונאום או הצהרה. תקשורת: עיתונות, ראיון ורשת חברתית.

רשימת השחקנים

הכינויים משמשים לזיהוי הדובר בפרוטוקולים. שם משפחה נפוץ (למשל כהן) עלול לתפוס דוברים אחרים — העדף שם מלא.

ייצוא וגיבוי

ייצוא לוורד

קובץ וורד מסודר לפי נקודות שבר: סינתזת הניתוח עם הפניות לציטוטים, כל מקור עם קישור, שדות הניתוח וכל הציטוטים עם עמודים ותיוג, ובסוף מפת השחיקה.

גיבוי מלא (JSON)

כל הנתונים — ניתוח, מקורות, ציטוטים ותיוג, מפת השחיקה.

ייצוא ציטוטים (CSV)

שורה לכל ציטוט, עם פרטי המקור והתיוג, לעבודה באקסל.

טעינת גיבוי

שחזור נתונים מקובץ JSON. הטעינה מחליפה את הנתונים שבדפדפן הזה.
